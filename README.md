# AS4103: Astronomical Investigation Project
### Angel Cerda Macías, Astronomy undergraduate at University of Chile 
<p align="justify">
Repository for the investigation project to be worked on during the spring term of 2026, under the supervision of Assistant Professor Valentino González. Based on the work of Shapley et al. (2025) using an AURORA JWST/NIRSpec Cycle 1 sample, we aim to first reproduce their analysis, and then extend it to different surveys, starting with CECILIA (Strom et al. (2023)).
</p>
